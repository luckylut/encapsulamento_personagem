# Personagem — Encapsulamento

O **Personagem** é um projeto desenvolvido em Java com o objetivo de praticar o conceito de **encapsulamento** dentro da Programação Orientada a Objetos.

O sistema simula um personagem que possui atributos como **vida, energia e nível**. Esses atributos são protegidos utilizando `private`, evitando que sejam alterados diretamente de fora da classe.

O personagem possui métodos responsáveis por realizar ações e controlar seus próprios dados, como receber dano, recuperar energia e verificar seu estado atual.

### Funcionalidades

* Controle da vida do personagem;
* Controle da energia;
* Definição do nível inicial;
* Recebimento de dano;
* Recuperação de energia;
* Verificação do status do personagem;
* Validação dos valores para evitar dados inválidos.

### Conceito utilizado

O principal conceito trabalhado no projeto é o **encapsulamento**, mantendo os atributos protegidos dentro da classe e permitindo que sejam acessados ou modificados somente por meio de métodos específicos.

### Objetivo

Praticar a criação de classes, atributos privados, métodos, getters, setters e regras de negócio, entendendo como o encapsulamento ajuda a proteger e organizar os dados de um objeto.
